Libraries

The analysis uses the tidyverse and lubridate for data management and dates, usRds to load USRDS files and extract Medicare claims, and flowchart to build the cohort so that the STROBE flow diagram and the analytic cohort come from the same code. These are the only library() calls in the project; other scripts rely on them.

#Data management libraries
library(tidyverse)
library(lubridate)

#Core library for the USRDS
library(usRds)

#Flowchart library
library(flowchart)

Constants

Numbers a reader might want to change live here as named constants, so downstream scripts and flowchart labels use one definition:

  • claim_years: the calendar years of institutional (IN) and physician/supplier (PS) claims searched for cryptococcosis.
  • lookback_days: the days of Medicare primary coverage required before the first cryptococcosis claim.
  • icd10_start_date: the ICD-9-CM to ICD-10 transition date. It is defined but not yet used by any script.

The plan sets index-date eligibility from the date range in which claims are complete for the release analyzed (analysis plan, section 2); claim_years is the current code’s fixed range.

Click to show/hide R Code 
claim_years <- 2006:2021                   #Years of IN and PS claims searched
lookback_days <- 365                       #Days of Medicare primary coverage required before the first cryptococcus claim
icd10_start_date <- as.Date("2015-10-01")  #ICD-9-CM before this date, ICD-10-CM/PCS on or after

Cryptococcosis codes

cryptococcus_ICD_list holds the ICD-9-CM and ICD-10-CM diagnosis codes for cryptococcosis, stored without periods. The usRds claim functions match them exactly. Section 3 of the analysis plan calls for a clinically reviewed list.

Click to show/hide R Code 
#ICD-9 and ICD-10 codes for cryptococcus (matched exactly by get_IN_ICD and get_PS_ICD)
cryptococcus_ICD_list <- c("1175", "3210", "B450", "B451", "B452", "B453", "B457", "B458", "B459")

Missed-opportunity code maps

icd9_map and icd10_map list the diagnosis and procedure codes for the categories that could signal an earlier presentation of cryptococcosis: lumbar puncture, increased intracranial pressure, brain infection, encephalopathy, headache, focal neurological deficit, stroke, pneumonia, pleural and mediastinal disease, signs of infection, and infection not otherwise specified. Each row records the category, whether the code is a diagnosis or a procedure, and the code. icd_combined_map stacks the two. No script uses the maps yet; they are the starting point for the opportunity ascertainment in sections 5 and 6 of the plan, which requires clinically reviewed, era-appropriate exact or prefix rules.
